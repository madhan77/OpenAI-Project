Call Center Login

Sign in with your Firebase email and password to access the Call Center control room. Successful authentication will redirect you to the dashboard with a bearer token.

Emulator Mode

The application is configured to use the Firebase Authentication emulator. Create test users with: 

firebase emulators:start --only auth

Then run:

firebase auth:import users.json --hash-algo=BCRYPT

or use the emulator UI to add accounts.
